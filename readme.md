## Overview
This repository documents the intrusion analysis, supporting technical artefacts, and local open-source Generative AI (**Ollama – Llama 3.1 8B**) usage for the `FlashGordon-PC` (`192.168.1.96`) incident investigation. In line with the COMP3010 assessment brief, all AI assistance was restricted to open-source models run locally, with outputs independently verified against primary network artefacts (PCAP, Snort, and Suricata logs) and external threat intelligence.

## Repository Structure

### `/AI_Evidence/`
* **`Prompt_TXT_Files/`** – Full text records (`Prompt_chat1.txt` – `Prompt_chat8.txt`) of all local Ollama interactions used for report structuring, research, and language refinement.
* **`Prompt_Screenshot_evidence/`** – Terminal screenshots verifying that `ollama run llama3.1:8b` was executed locally.

### `/Tool_Outputs_and_analysis/`
* **`Screenshots/`** – Full-resolution Wireshark, Snort/Suricata, PowerShell `Get-FileHash`, VirusTotal, and OSINT screenshots supporting the report.
* **`gerv.gun_download_Proof/`** – Extracted HTTP stream data (`gerv.gun`) screenshot proof without hosting live malware binaries.
* **`Investigation_outputs_and_planning.pdf`** – Raw investigative working notes, packet tree breakdowns, and hash verification records.
* **`WireShark_Filters_Used` & `recent_common`** – Exact Wireshark display filters and raw filter history used during packet triage for full reproducibility.

## AI Log Format
Each text log in `/AI_Evidence/Prompt_TXT_Files/` follows a consistent structure to demonstrate transparent and critical AI usage:
* **`Prompt:`** The exact query submitted to the local Ollama model.
* **`Response:`** The raw output generated by the model.
* **Review & Hallucinations:** A post-interaction evaluation detailing where the model was useful, any inaccuracies or hallucinations identified (such as word-count miscalculations, IP misclassifications, or dropped forensic details), and the manual steps taken to validate the findings.
