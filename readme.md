## Overview
This repository documents the use of local, open-source Generative AI (**Ollama**) during the intrusion analysis and incident reporting for `FlashGordon-PC` (`192.168.1.96`). In line with the COMP3010 assessment brief, all AI assistance was restricted to open-source models run locally, with outputs independently verified against primary network artefacts (PCAP, Snort, and Suricata logs) and external threat intelligence.

## Repository Structure
* `/Prompt_TXT_Files/` – Full text records of all Ollama interactions used for problem exploration, report structuring, and language refinement.
* `/Prompt_Screenshot_evidence/` – Supporting screenshots of local Ollama terminal sessions verifying open-source model usage

## Log Format
Each log file follows a consistent structure to demonstrate transparent and reproducible AI usage:
* **`Prompt:`** The exact query submitted to the local Ollama model.
* **`Response:`** The raw output generated by the model.
* **Review & Hallucinations:** A post-interaction evaluation at the bottom of each log detailing where the model was useful, any inaccuracies or hallucinations identified, and the manual steps taken to validate the findings.
